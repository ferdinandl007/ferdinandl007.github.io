Paste Muse Privacy Policy

Effective November 22, 2026

Clipboard history

Clipboard monitoring starts when you enable it in the welcome guide or Settings. Paste Muse stores the text, links, images, and other supported items you copy while monitoring is active, along with source app and timestamp where available. History stays in the app’s local macOS container. Paste Muse skips copies from excluded apps and items marked concealed or transient. It protects recognized credentials and masks them in clipboard tool responses.

You can pause monitoring, turn off image capture, exclude apps, set a retention limit, and remove individual clips or all history. Pinning keeps a clip from being removed by retention. Paste Muse uses the macOS Keychain to protect the key for encrypted clipboard payloads.

On-device features

Clipboard search, image text recognition, and supported titles run on your Mac. Apple Intelligence provides short titles on supported Macs when enabled. EmbeddingGemma provides semantic search on Apple silicon. Paste Muse has no user accounts, advertising, analytics, tracking, or hosted AI service.

Optional online previews

Each preview category starts off. Enabling a category allows Paste Muse to request previews when corresponding clips are displayed. Link previews contact the linked site and may contact services that provide its metadata or images. Address maps use Apple Maps. Public IP lookups use IPWho and Apple Maps. Flight previews use public flight data services such as ADSBDB and Airplanes.live, and may use Google for schedule information.

Those services receive the copied value needed for the request, along with normal connection information such as the requesting IP address. Their own privacy policies govern their handling of requests. You can turn each category off in Settings. Paste Muse does not receive those requests on a developer-operated server.

Optional localhost tools

The MCP server starts off. If you enable it, a client with the access token can connect on this Mac and search, read, copy, pin, or delete clipboard history, and write to the clipboard. The server binds to 127.0.0.1 and stores its token in the macOS Keychain. Share the token only with clients you trust. Those clients are responsible for how they handle data they receive.

Command-line access also starts off and has its own switch. It lets agents on this Mac search, read, or restore clipboard history and work with supported clipboard settings. Paste Muse can install a skill or MCP connection into an agent folder you select. The installed instructions and configuration contain the Paste Muse command and no clipboard history or access token.

API key access is a separate option. Clipboard tools mask recognized credentials. If you enable the API Key Vault for clients, its approval settings govern access to credential values.

Permissions and support

Accessibility is optional and supports direct pasting into another app. When you use the app picker to exclude a source, Paste Muse reads the selected app identifier. Launch at login is optional. Paste Muse does not sync your history through iCloud.

For privacy questions or support, see the Paste Muse support page. Please omit clipboard contents and credentials from public reports.
