Prism Support

Prism is a web and immersive video player for Apple Vision Pro.

Playing a video

  • Paste a direct MP4, MOV, or HLS link into the address bar, or choose Open File on the Start Page.
  • On a compatible web page, use the site’s Play button or select Play in Prism in the toolbar.
  • For a clip with a green backdrop, open Viewing Options and turn on Green Screen Passthrough. The Start Page’s Try Green Screen demo works offline.
